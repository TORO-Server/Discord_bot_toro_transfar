# Discord_bot_toro_transfar

TORO サーバーの乗換案内 ([toroapp_transfar](https://github.com/TORO-Server/toroapp_transfar)) を、Discord のボット (自動で動く Discord のアカウント) として使えるようにしたものです。

- Node.js で書かれています
- Discord.js 13 を使います (package.json が正本です)
